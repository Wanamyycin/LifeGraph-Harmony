# AI 助手实施方案

2026-10-25。用户已批准聊天中的十项设计规范，并授权常规实现决策；初期仅做本地验证，用户随后授权模拟器和小额真实调用，设备结果见 ai-api-device-check.md。沿用 ArkUI / 本地 RDB，按用户最新要求改为直连 OpenAI 兼容 Chat Completions API，不再经过原 `/api/v1/ai/chat` 代理。原 Expo 与后端工程保持只读。

## 范围与决定

- 本地工具负责人物／事件的组合检索、分页、共同经历和时间分布统计，以及当前版本使用说明。模型负责组织语言、扩展检索词和给出旁观者解读；建议不写回业务记录。
- 连续追问发送最近完整对话轮次，保留明确的上下文窗口说明；每轮工具查询基于同一份新快照，旧回答不是当前事实依据。
- 事件列表返回标题、日期、参与者、正文摘要、匹配原因和可引用 ID；详情按需读取。共同经历与正文提及分别计数；同名人物明确提示歧义。
- 关系分析工具提供全量统计及分页事件，而不在客户端硬编码分数。系统规范要求依据充分才给 1～5 建议，说明证据与推断、局限及替代解释。模型结论质量仍需真实服务验收。
- 引用仅允许本轮实际查询到的记录；模型生成的未核对内部链接不可直接跳转。显示“本次查询记录”，不把查询过的每条记录都冒充结论证据。
- 会话独立保存在 app_config 的 assistant_conversation_v1 键，包含用户／助手文本、查询来源和时间，不存工具原始输出、图片或音频。由现有备份一并保存／恢复，清空会话不修改人物和事件。容量达到限制时明确提示，不静默删除旧聊天。
- 控制器统一处理持久化、取消、清空、迟到回复与错误。失败／取消的问题保留状态，可重新填写；只带完整成功轮次进入后续上下文。
- UI 沿用原 Palette、字体与圆角。顶部提供使用说明／清空，正文为对话和可展开来源，底部提供发送／停止；完整复制、推荐问题、自动滚动、长回复展开。服务设置说明所需文字由配置服务处理。
- Markdown 用原生文本／横向表格渲染标题、强调、代码、引用、列表和安全链接，不执行 HTML。外部 http(s) 链接经系统浏览器打开；内部来源链接由应用校验和路由。

## 服务设置与直连协议

- 点击“服务设置”打开原生弹窗，填写接口 URL、API Key、模型 ID；未配置时点击发送也会打开弹窗，保留输入的问题。取消不应用草稿，保存配置不自动发起模型请求。
- 接口 URL 支持根地址（自动补 `/v1/chat/completions`）、版本／自定义前缀（补 `/chat/completions`）或完整 Chat Completions 地址；保留查询参数，不重复追加路径。HTTP 可用于本地兼容服务，公网地址应使用 HTTPS。
- 请求以 Bearer 携带密钥，使用 `model`、`messages`、嵌套 function tools、JSON 字符串 arguments 和 `tool_call_id`；按 `choices[0].message` 解析文本或工具调用。协议依据为 [OpenAI Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。模型必须支持工具调用；只有文本对话能力的服务无法完成本机记录查询。本轮使用非流式响应，等待时显示查询进度并支持停止。
- 配置通过原生 ASSET 安全存储保存为一个加密条目，禁用同步，采用首次解锁后可访问的策略；使用卸载即删除的默认策略，不申请跨卸载持久化权限。配置与业务数据库、聊天、媒体及 ZIP 备份分离。换设备后需重新填写，恢复业务备份不替换当前服务配置；旧 ProfileConfig.apiBaseUrl 字段仅保留兼容，不再作为请求地址。
- 安全存储不可用或不想保存时，可取消“在本机安全保存”，本次运行使用内存配置；重开后重新填写或载入此前已安全保存的配置。安全保存失败不替换当前配置，不显示成功。
- [ASSET 官方说明](https://raw.githubusercontent.com/openharmony/docs/master/zh-cn/application-dev/security/AssetStoreKit/asset-js-add.md)规定单条 SECRET 上限为 1024 字节；本实现对完整配置的 UTF-8 字节数提前校验，超限明确提示仅本次使用。内存模式仍支持最长 2048 字符 URL、4096 字符 Key、200 字符模型 ID。
- 已有密钥不回填到输入框；地址不变时留空可保留，更换接口地址必须重新填写 Key。密钥不写入日志或错误文本，网络错误不回显服务返回正文。禁止自动重定向，避免将凭据转发到其他地址；请求不使用缓存。认证失败、模型／接口不存在、限流／额度、超时及非兼容响应均给出提示。

## 实施与验证顺序

1. 先扩展查询工具、帮助目录、共同经历统计、分页及可信来源；用固定本地数据测试。
2. 加入多轮上下文、检索规范、工具预算与回答来源；使用受控 transport 验证协议和边界，不伪称真实模型效果。
3. 会话持久化与控制器：验证保存失败、取消／清空、迟到响应、重启恢复、原业务只读及备份往返。
4. 原生 Markdown 与 AI 页交互；编译 SDK 检查，并在主机验证解析和链接约束。
5. 运行全部本地回归和生产构建；记录剩余的设备、浏览器跳转、剪贴板、键盘、真实模型与性能验收项。

## 已落地内容与限制

- 13 个工具：原 11 个工具扩展字段、分页和正文／地点／标签检索，新增 getRelationshipContext、getAppHelp。人物可显式包含隐藏记录；同名描述和隐藏标记保留。每轮个人查询使用同一份新快照，帮助查询不读取个人快照。
- 模糊检索使用本地关键词扩展、常用同义词与结构条件，模型可继续改写检索词；没有引入向量库，不承诺任意语义描述都能召回。否定情绪不会扩展为正面情绪。
- 共同参与、目标单独参与、仅姓名提及分别计数；全量统计与按年分布在本地计算。工具没有“自动打分”或写入能力，关系解读和强度建议由模型基于证据组织，准确性仍需真实模型评估。
- 多轮带入最近 6 轮成功问答，上下文窗口 24000 字符；早期单条长回复带入前 8000 字并说明摘要窗口。全文继续留在本机。失败／取消问题不进入下一轮历史。
- 单问题最多 6000 字；每轮最多 8 次服务往返、48 个工具调用，单批工具输出 90000 字符、累计工具输出 120000 字符。达到边界明确提示缩小范围，不静默把部分数据当完整结果。列表默认 50 条，最多 100 条，支持 nextOffset。事件详情正文最多 12000 字，摘要最多 600 字，均带截断标记。
- 聊天最多 1000 条消息、序列化 UTF-8 1000000 字节；达到容量提示先备份／复制再清空，不自动删除旧聊天。界面先渲染最近 40 条，可分批查看更早记录。查询来源最多保留 100 个入口并说明限制，优先保留回答实际引用的来源。
- 查询进度单独更新，不为每个工具进度反复复制整份聊天；实际设备接近容量时的性能仍需测量。
- 来源只从本轮工具输出中收集并核对 ID；查询记录列表不宣称每条都证明模型结论。打开来源时再核对当前记录是否存在；已删记录给出提示。清空／离开／重新加载会使迟到回复和来源跳转失效。
- 进入后台、返回离开 AI 页或点停止会取消当前查询；中断问题保留“已停止”状态。保存失败保留屏幕回复并提示复制，不重新请求模型。备份恢复等待会话写入结束，再载入恢复后的聊天。
- 原生 Markdown 支持常见表格、标题、强调、代码、引用、列表、安全链接；表格横向滚动。HTML 和远程图片不执行／自动加载，不承诺与 RN 的全部嵌套 Markdown 规则完全一致。
- NativeApp 接入使用说明、推荐问题、服务设置、清空确认、复制全文、来源跳转、停止、重新填写、自动滚动与长回复展开。AssistantPreview.ets 提供浅色／深色演示，不读取真实记录，也不是设备验收。

## 本轮验证记录

本地回归共 94 项：人物与运行环境 11、真实 SQLite 业务 19、图谱／ZIP／AI／查询 13、SDK 适配器 10、AI 专项 28、OpenAI 直连适配 13。SQL 测试验证聊天保存／清空不改变业务快照、聊天随备份恢复、真实磁盘关闭重开读回，以及中断状态恢复。AI 专项覆盖同名／历史人物、正文与同义词、237 条事件分页、共同与提及区别、可信来源、先查工具约束、多轮窗口、停止／清空／迟到响应、保存失败、中文容量与 Markdown。直连适配验证地址规范化、请求／响应转换、实际 transport 的工具往返、取消与资源释放、错误脱敏、安全配置原子读写及超限／不可用失败；HTTP 与 ASSET 由受控主机替身提供。

构建与测试日志：evidence/build-default.log、person-test.log、core-test.log、extended-test.log、native-adapters-test.log、assistant-test.log、openai-test.log。上述主机测试使用替身；随后已覆盖安装当前 HAP，并在真实 DeepSeek 服务完成一条简短查询及设备安全配置／聊天重开读回，详见 ai-api-device-check.md。源工程和后端保持只读；原生应用内部的工具结构由适配层转换为 OpenAI 格式，不再依赖原后端。

仍待验收：用户所选提供方／模型的工具调用兼容性、检索规划、追问和关系分析质量；设备安全存储与进程重开读回、弹窗保存／取消已通过本轮手测；仍待验证设备重启、原生剪贴板、链接／来源跳转、键盘与自动滚动、表格布局与大字体；真实网络超时／前后台及聊天接近容量时的设备表现。本地测试与本轮空业务库的简短查询不能替代这些结果。

DeepSeek 官方 HTTPS API 使用非思考模式，避免默认思考模式要求回传 reasoning_content 导致工具后续请求失败；其他服务不添加此扩展参数。依据与结果见 [API 手测记录](ai-api-device-check.md)。
