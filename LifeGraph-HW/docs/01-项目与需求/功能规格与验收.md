# 功能规格与验收

版本：1.0.0　｜　代码基线：`0cba655`

本规格描述正式入口的实际行为。验收场景用于检查行为，开发侧检查见相关测试脚本；正式上架及平台检测结果见[上架与平台检测结果](../04-迭代与质量保障/上架与平台检测结果.md)。

## 1. 导航与保存

底栏依次为图谱、记录、新建事件、人物、我的。中间加号直接打开事件表单；“我的”使用齿轮图标。首页、记录页和人物页没有重复进入个人页面的右上角菜单。

### D-01：本机数据

首次初始化创建“我”、四种关系类型、五种生活分支及六种情绪标签。人物、关系和事件保存到RDB；媒体保存到应用私有目录。界面预览不保存数据，不作为持久化验证环境。数据库提交后若刷新失败，界面提示核对结果，避免重复提交。

验收：创建人物和事件后停止进程、重新启动，核对内容；非法输入应被拒绝且不留下部分关联。

## 2. 人物与关系

### P-01：人物资料

人物名称不能为空，可填写描述、选择图片头像。普通人物名称没有全局唯一约束，允许同名，不自动合并。头像引用必须有效且指向图片。“我”通过“我的→个人资料”编辑，不能从普通人物入口删除。

个人资料中称呼最多24字、个人见解最多200字，生日可选且可清除，日期不得晚于当天。

### P-02：人物关系

一行关系包含目标人物、类型、强度。目标不局限于“我”；不允许关联自身。同一人物对可有不同类型；相同人物对和类型不重复建边。强度界面为1—5整数、默认3，数据层同时接受空值。

编辑时以人物ID保存目标，以稳定行ID识别关系行。已有的隐藏人物关联可保留和修改，不允许新建指向隐藏人物的关系。

验收：为A选择B，修改强度、保存并重开；数值随滑条变化，目标仍为B。删除一行后其余行不应串位。

### P-03：删除

| 操作 | 结果 |
| --- | --- |
| 保留历史 | 隐藏人物，保留历史关系和事件引用 |
| 彻底删除 | 删除人物及其关系、参与关联；仅由该人物参与的事件也删除；多人事件保留 |
| 删除事件 | 删除事件及参与者、分支、情绪、附件关联；不删除参与人物 |

隐藏人物已没有事件引用时，后续清理可将其及关系删除。媒体是否删除由剩余引用决定，不以从界面消失作为彻底清除所有副本的保证。

## 3. 事件与媒体

### E-01：事件编辑

标题不能为空，至少选择一位参与者，发生时间须有效。正文、手填地点、分支、情绪可留空。新事件默认包含“我”，但允许取消并记录其他人物的事件。参与者从已有记录中选择，不根据正文自动创建人物。

参与者、分支、情绪支持多选；“未设置”清空分支。关系类型、分支和情绪可在管理页新增、改名、删除。删除分类移除其关联，保留人物与事件本身。

### M-01：附件与录音

图片和音频通过系统选择器选择后复制到应用目录。图片可设为封面、查看大图和移除。录音在用户点击后申请麦克风权限；拒绝时可继续文字记录或导入已有音频。录音中限制其他跳转，退后台时停止录音；初始化失败或会话释放时清理临时捕获文件。

取消编辑可清理本次新增且无有效引用的附件。更换头像和删除事件时，仅清理无其他引用的媒体。文件清理失败保留诊断信息，不将仍被引用的文件一并删除。

验收：同一图片被多个已保存对象引用时，移除其中一个引用不应破坏其他对象；取消编辑不应删除原有附件。

## 4. 图谱

### G-01：图谱范围与交互

| 图谱 | 数据范围 |
| --- | --- |
| 首页人际图 | “我”与直接关联的活跃人物及关系；可按关系类型筛选 |
| 人物关系与事件图 | 选中人物的直接关系，以及该人物参与、符合分支筛选的事件和活跃参与人 |
| 个人生活图 | “我”参与、符合分支筛选的事件；直接连接中心、事件及其他活跃参与人，不生成独立分支节点 |

同一事件命中多个分支时仍只生成一个事件节点。图谱隐藏已删除人物节点，但记录本身可保留其历史参与信息。关系强度为用户输入，不作专业或客观关系判断。

支持节点拖动、画布平移、节点跳转、缩放按钮及主题切换。缩放比例为0.25—2，按钮倍率为1.3。图谱绘制区域有固定边界，节点越界时会被裁剪；此行为与原生列表的边缘回弹不同。

## 5. 记录与检索

### T-01：记录时间线

页面按月分组，默认最近在上；可切换升降序、展开或折叠月份与记录。初始展开首组，其余组折叠。筛选同时应用：标题/正文关键词、选定人物、生活分支。关键词忽略大小写；多个分支之间为“任意命中”，不同筛选维度之间为“同时满足”。

人物下拉项显示“与某人”，实际只要求该人物参与，不额外要求“我”参与；人物详情的“共同的生活记录”同样按该人物参与检索。示例：事件参与者为[A,B]时，选择A仍可查到，不因缺少“我”而排除。桌面卡片的共同记录计数则要求“我”和该人物同时参与，两者口径不同。

### S-01：全局搜索和页面状态

全局搜索独立查找人物名称、描述或事件标题、正文，不继承记录列表的分支筛选。详情返回保留当前搜索上下文。进入新的列表入口时可清空该列表关键词，但已有的人物和分支筛选不保证全部自动清除；组合筛选无结果时可使用“清除筛选”重置。

## 6. 卡片与备份

### C-01：关系微图

桌面卡片为2×2，除中心“我”外最多选六位活跃人物。全部实例共用配置。默认以序号隐藏姓名，可改为名字首字或记录中的称呼；卡片圆点显示短标签，辅助功能文本可包含截断称呼。卡片不展示照片、头像、音频、事件正文或地点。人物点击进入相关详情，加号进入事件编辑。编辑、录音或数据变更期间暂存跳转请求。

### B-01：备份恢复

用户通过系统文件界面导出、选择ZIP，格式标识为`lifegraph-harmony`、版本为1。备份包括12张业务与配置表及其媒体文件；卡片Preferences不包含在ZIP中。恢复先预览再确认，在事务内替换当前数据。清单上限16MB，单附件512MB，ZIP写入及解包累计大小按1GB限制检查。

格式、大小、路径、CRC及引用不合法时拒绝恢复；CRC不是来源认证，ZIP不提供应用内密码加密。应用内删除不会删除已导出的文件或系统备份。

## 7. 交互与质量约束

### Q-01：操作反馈

保存期间禁用相关操作，选项使用响应式状态显示选中结果。原生滚动容器使用`EdgeEffect.Spring`，不足一屏时也启用回弹。深浅色覆盖原生内容、图谱及媒体控件。权限拒绝、校验失败与恢复覆盖均有对应提示。

主要验证入口为`test-person.cjs`、`test-core.cjs`、`test-extended.cjs`、`test-native-adapters.cjs`、`test-desktop-card.cjs`及`test-offline-release.cjs`。自动化结果不能替代真实设备的选择器、键盘、录音和图谱视觉验收。
