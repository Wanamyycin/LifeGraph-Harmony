# Life Graph 产品与需求说明

版本：1.0.0　｜　代码基线：`0cba655`

## 1. 项目定位

Life Graph（生活脉络）是一款运行于 HarmonyOS 的个人生活记录应用，以人物、事件及两者之间的联系组织记忆。用户可以记录一位朋友、一段经历，再通过关系图、人物详情和时间线回顾。应用不要求注册账号，业务记录在本机保存，支持用户主动导出和恢复备份。当前1.0.0版本已正式上架华为应用市场。

项目沿用了原 Android/Expo 版本的业务概念，在鸿蒙版中重新实现界面、本地存储、媒体操作和桌面卡片，不迁移旧用户数据。

## 2. 需求来源

2026年4月13日至14日的前期调研包含70条问卷记录、四份涉及五位学生的访谈笔记。问卷中47人选择“比较需要”或“非常需要”将事件关联到多个人物；访谈反映出按人物找回经历、记录分散和整理负担等问题。另有受访者认为图谱过于正式，或不愿用分值衡量关系。这些差异决定了应用同时提供图谱与列表，关系强度保留为手动记录。

研究的样本构成、逐题统计及局限见[用户研究报告](../02-用户研究/用户研究报告.md)。

## 3. 使用场景

| 场景 | 用户任务 | 产品回应 |
| --- | --- | --- |
| 记录一位重要的人 | 保存称呼、备注、头像及与他人的关系 | 人物列表、人物详情、任意人物对的关系编辑 |
| 聚会或旅行结束后 | 把文字、照片或语音与参与者关联 | 事件表单、多选参与者、图片与音频附件 |
| 想起一段模糊经历 | 根据人物、关键词、时间或分支查找 | 人物相关记录、全局搜索、按月记录列表及筛选 |
| 回顾一段生活 | 在时间和人物联系之间切换 | 人际图、人物事件图、个人生活图 |
| 从桌面快速进入 | 少占屏幕空间，避免直接展示私人正文 | 2×2关系微图、默认隐藏姓名、快速记录入口 |
| 更换设备前保存资料 | 自主保留人物、事件及媒体 | 本地ZIP备份与恢复 |

## 4. 当前交付范围

| 已提供 | 当前边界 |
| --- | --- |
| 人物、头像、备注、关系类型及1—5级关系强度 | 名称是用户填写的称呼，不提供实名校验或自动合并同名人物 |
| 事件标题、正文、时间、地点文字、多参与者、分支、情绪、颜色 | 地点手动填写；分支和情绪为用户标签，不进行自动识别 |
| 图片、音频导入、麦克风录音与播放 | 不提供视频、语音转文字或图库全量扫描 |
| 图谱拖动、缩放、筛选、节点跳转 | 图谱采用ArkWeb中的本地D3/SVG；节点允许移出视野，不提供边缘吸附 |
| 按月记录列表、排序、折叠、关键词及人物筛选 | 人物筛选表示“该人物参与”，不额外限定“我”必须参与 |
| 个人资料、四种主题、明暗模式、分类管理 | 设置保存在本机，无账号同步 |
| ZIP备份、恢复、空间统计、桌面关系卡片 | 恢复替换本机数据；卡片设置不在ZIP中 |

账号登录、会员支付、云同步、在线AI助手、自动定位、通知提醒和应用锁不属于1.0.0的可用功能。

| R-01 | 保存人物，并建立任意两人之间的关系 | P-01、P-02 |
| R-02 | 一件事件关联多位参与者及媒体 | E-01、M-01 |
| R-03 | 从图谱、人物和时间重新找到记录 | G-01、T-01、S-01 |

| R-06 | 提供紧凑的桌面查看与记录入口 | C-01 |
| R-07 | 保存、选择和异常操作具有可识别反馈 | Q-01 |

需求对应的输入、约束和验收场景见[功能规格与验收](功能规格与验收.md)。
