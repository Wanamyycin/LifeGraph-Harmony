# 鸿蒙全量迁移实施记录

2026-10-21 用户已授权开始全量迁移，并允许替换不适配的库／API；以实际可用、流畅、尽可能接近原应用为优先级。沿用已审阅设计的功能范围，不迁移旧数据，不补齐原项目未实现项。

## 顺序

1. 建立原 11 表＋本地配置、版本迁移、串行事务和应用级运行时；用真实 SQLite 主机适配器验证业务 SQL，不冒充设备 RDB。
2. 接通人物、关系、事件、分支、情绪和删除策略，恢复与原应用接近的导航、列表、表单与主题。
3. 接入离线 D3/ArkWeb 图谱，验证消息协议及生命周期。
4. 接入系统图片／文件选择、沙箱媒体、录音播放；处理权限、取消和失败。
5. 补齐个人资料、统计、主题持久化、自有备份和已有 AI 接口。
6. 全量构建、业务回归和设备测试交接，逐项记录未验证／不适配部分。

## 实施约束

- 原 Expo 目录作为只读参考，所有鸿蒙改动在 LifeGraph-HW。
- 现有试验原型可作为回归参考；正式运行改用新库，不读取或删除试验用户数据。
- 普通页面预览也只读；API Mock 返回不能作为写入成功证据。
- 原生 API 按本机 SDK 声明核验并编译；无法验证的运行行为保留待验状态。
- 不自动配置用户签名、不伪造后端成功；设备不可用期间继续独立实现与主机验证。
