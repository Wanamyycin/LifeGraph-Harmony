# 原生界面调整

2026-10-26。根据用户对 HTML 提案的修正直接修改原生应用；HTML 仅作为视觉参考，不以其删减过的表单替代正式功能。

## 已实现

- 默认首页仍是 NativeGraph／ArkWeb 离线 D3 图谱。保留力导向布局、圆形人物节点、拖动、缩放、关系强度距离与节点跳转，未改为静态示意图。图谱上方移除重复入口，只保留关系筛选，让图谱占据主要空间。
- 底栏依次为图谱、记录、纯色圆角方块＋、人物、助手。中间按钮是新建事件动作，不是一个空页面。四个页面各有独立入口、选中状态；记录与人物分别保存搜索词。
- 右上角“我”／用户头像扩大为 48vp，打开原有我的页；个人资料、分类管理、分支图谱、主题、空间统计及备份入口保留。
- 人物与事件使用 Navigation 对话目的地承载完整表单，底部弹出、占可用区域的 94%，可滚动。沿用原来的保存、返回、分类管理与媒体清理流程。
- 人物保留头像、姓名、描述、任意其他人物间的多条关系、关系类型、1～5 强度及原有历史人物限制。事件保留标题、正文、日期、地点、参与者、分支、情绪、颜色、图片、音频、录音、封面及附件管理。
- 列表改为分隔行，记录按日期与正文区分层级；颜色仍有小圆点提示，不移除用户的事件色。筛选使用下划线页签，表单内的多选控件保留选中颜色与勾选反馈。
- 调整浅色／深色基础颜色、字号、空状态文字和按钮圆角。原四个主题及用户已选主题保留；图谱颜色由同一套 Palette 生成，原始 D3 逻辑与调参保留。
- 助手可从底栏进入，其他助手入口统一回到同一主页面，避免同一个 Scroller 同时绑定多个聊天列表。离开助手会使待跳转来源失效并停止当前查询，自动滚动只对当前可见的助手生效。

## 验证与边界

本地六组回归共 95 项通过（11＋19＋13＋10＋29＋13）。新增导航可见性用例覆盖助手主页面、编辑弹层、我的页、旧式助手路由与来源详情。主程序构建通过，原生数据库与媒体业务代码未因视觉调整重写。

本轮模拟器离线，尝试重连未成功；没有启动模拟器、安装本轮 HAP 或发送真实 AI 请求。新版导航、完整弹层、键盘、深色图标、长文字和大字体仍需设备验收，之前的设备截图不是这版的视觉证据。

建议手测：冷启动查看图谱与五个底栏位置；分别进入记录、人物、助手再返回图谱；从不同页面点中间＋，取消后回到原页面；新建人物选择两名不同对象与不同关系强度；新建事件组合参与者／分支／情绪并添加媒体；表单内进入分类管理再返回，确认草稿保留；最后验证深色、图谱拖动和缩放。此轮没有扩展静态 HTML 展示页。

旧按钮审计脚本的导航标签已兼容到新控件 ID，滚动优先使用顶层弹层；部分原有按钮审计仍断言旧标题／勾选式筛选，其历史结果不可作为新视觉版本验收，应按本记录的流程重新核对。
