# 离线版本代码检查

日期：2026-10-28。

## 本轮范围

- 用户确认应用定位为离线记录工具；只检查和修改代码，不办理备案、开发者账号或资质。
- 用户暂未生成本应用的华为托管隐私声明，明确本轮先不处理，因此未接入隐私 SDK、未填入假链接或华为自身的隐私政策。隐私声明仍是后续提审前的待办。

## 代码改动

- 主模块仅声明麦克风权限，移除 `ohos.permission.INTERNET`。录音仍由用户点按时申请麦克风权限，拒绝后可导入音频。
- 删除不再使用的原生 API 网络客户端、AI runner、安全配置读写和服务配置界面。纯函数协议／历史聊天编解码暂留，以兼容已有本地记录与备份；应用无 AI 页面路由或后台 AI 初始化。
- 不读取、不打印、不导出旧安全存储中的密钥，也不自动删除用户旧聊天数据。
- 图谱使用包内 HTML、D3 和交互脚本；Web 显式禁止联网、远程图片及混合内容，同时保留本地脚本和图片 data URI。
- 应用显示名称沿用 `Life Graph`，供应商品牌字段由模板 `example` 改为 `LifeGraph`，模块描述去掉“原型”。品牌字段不是法律主体证明；本轮不捏造运营主体信息。
- 沿用原 Expo 工程的透明叶子图作为应用层叠图标前景、能力图标与启动图，使用品牌绿色背景，替换默认蓝色四格。未重新绘制原图。
- 包名仍为 `com.lifegraph.harmony.spike`，未擅自改成一个未经发布后台确认的新包名，避免形成另一个应用而无法覆盖现有安装。该标识可以使用，但正式发布前需与实际登记信息一致。

## 离线边界

无账号、广告、云同步、分析统计或应用主动网络请求。用户手动导出的 ZIP 会离开应用私有目录；系统备份／换机能力由系统管理，本轮未改变其开关，因此不宣称数据在所有情况下绝不会离开设备。

`scripts/test-offline-release.cjs` 检查权限白名单、无原生网络调用、图谱资源本地化和图标／名称引用。`scripts/test-openai.cjs` 仅保留旧协议的纯函数测试；不再测试已删除的网络／密钥功能。

## 后续仍需验收

正式发布签名及上传、最低兼容系统与真机、媒体／备份往返、大数据量性能等，不因本轮代码整理而自动视为通过。原有两项生活分支图谱测试的实现／预期差异仍需独立处理。
