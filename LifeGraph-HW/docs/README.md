# Life Graph 项目文档

Life Graph（生活脉络）将人物、关系和事件组织为可检索的私人生活记录。鸿蒙版采用ArkTS与ArkUI构建业务界面，以RDB保存数据，使用本地Web图谱呈现联系，并提供紧凑桌面卡片及ZIP备份。

**适用版本：1.0.0　｜　代码基线：`0cba655`　｜　统一核对日期：2026-10-30**

当前包名为`com.njulifegraph.lifegraph`，1.0.0版本已正式上架华为应用市场。正式范围为免费本机应用，不提供登录、会员、应用自有云同步或AI助手。旧版概念与当前实现分别记录。研究时间、实现与修复时间、测试执行时间分别依据原始材料、提交记录和验证结果标注；统一核对日期表示本套文档与代码的核对时间。

## 证据与适用边界

需求来源是早期概念调研，不作为鸿蒙成品的满意度或留存结果。华为平台上架测试覆盖6台设备、128个用例，结果通过；软件包检测得分100、结果通过。原始截图与覆盖范围见上架与平台检测结果，开发侧回归说明保留在对应专题与工程脚本中。

原始课程资料、答卷和访谈在仓库资料区保留以供追溯，公开提交使用匿名汇总。本目录不包含私人答卷、证书、临时诊断资料或开发对话。
