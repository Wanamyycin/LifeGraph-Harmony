# 外观与深色适配

## 1. 颜色体系

应用提供森林、海洋、日落、极简四套主题，以及跟随系统、浅色、深色三种显示模式。原生页面使用统一Palette，图谱按同一外观判定选择随包HTML，避免依赖某个固定背景色判断明暗。

深色适配曾出现图谱浅色矩形、输入提示过暗和主操作文字对比度不足。背景判断、控件默认颜色与应用内选择的模式不同步是主要原因。

## 2. 实现措施

- 原生ColorMode随应用选择同步；跟随系统时解除应用覆盖。更新去重，失败时允许重试，窗口销毁时解除回调。
- 输入框显式设置文字、提示和光标颜色；搜索、下拉选择和媒体控件使用主题颜色。
- 主要操作与危险操作分别提供前景颜色，不以固定白字匹配所有主题。
- 图谱HTML、SVG、节点文字和缩放按钮使用与原生页面一致的外观分支；普通页面返回保留Web实例。

底栏、选中标签和按钮禁用状态同时承担操作反馈。选中状态由应用状态驱动，不能仅依赖系统控件的默认外观。

## 3. 验证与边界

宿主测试覆盖主题选择、图谱背景、原生模式更新和失败重试等逻辑。历史模拟器检查确认深色图谱背景、日期选择器和关系下拉菜单可辨，并检查手动浅色、深色及跟随系统之间的切换。

外部文件或照片选择界面由系统提供，不能根据应用内部配色推断其全部窗口均已适配。禁用态、大字号及辅助功能仍需设备检查。此处不沿用已退出产品范围的助手输入页面作为当前验收对象。
