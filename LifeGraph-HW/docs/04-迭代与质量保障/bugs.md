不同问题的验证依据分别记录，不把旧版检查次数汇总成当前版本的设备通过数量。

## 2. 已知行为与限制

| 项目 | 当前表现 | 使用与验收说明 |
| --- | --- | --- |
| 图谱边界 | 节点可随拖动移出画布，并被页面边距内的边界裁剪 | 不是原生回弹产生的遮罩；图谱未实现越界吸附 |
| 人物相关记录 | 人物详情与记录页按该人物参与筛选，不强制“我”同时参与 | 不将界面“共同”措辞解释为严格双参与校验 |
| 筛选上下文 | 记录页可保留先前人物与分支条件 | 无结果时清除组合筛选；不能承诺每次跳转都自动重置 |
| 卡片刷新 | 设置落盘成功后，系统卡片可能暂时未刷新 | 界面区别保存成功和刷新失败；以应用内数据为准 |
| 媒体释放 | 无引用文件按清理流程移除，失败时保留诊断 | 不承诺删除操作立即安全擦除所有物理副本 |

## 3. 回归重点

1. 人物关系目标、强度和多行编辑在保存、重开后保持一致。
2. 事件多选、取消编辑、修改分类及详情返回不串用旧状态。
3. 修改或删除一个引用不破坏其他记录的媒体；异常恢复保留原数据库。
4. 图谱头像、深色、前后台恢复、缩放与持续拖动分别检查。
5. 短列表回弹、横向筛选条与表单控件的手势协调使用真实设备确认。

发布验证见[上架与平台检测结果](上架与平台检测结果.md)，操作路径见[使用手册](../05-部署与使用/使用手册.md)。
