# 关系图渲染稳定性案例

修复提交：`3f8ebf0`　｜　实验日期：2026-10-28

## 1. 现象与假设

持续拖动时，整个图谱偶发短暂空白后恢复。诊断同时检查页面加载、图谱消息、DOM清空和SVG节点数，捕获空白时没有重载或数据重发，节点仍存在。因此该实验中的问题位于Web画面合成或送显路径，而不是业务数据丢失。

## 2. 对照实验

环境为1280×2832的DevEco模拟器。保持既有2节点主页与3节点人物图不变，连续按住后进行约240次位置移动，并使用系统屏幕截图采样。以下为采样结果，非逐帧录像统计。

| 方案与场景 | 样本张数 | 空白 | 黑框 |
| --- | ---: | ---: | ---: |
| 同步渲染，主页连续拖动 | 50 | 1 | 0 |
| 同步渲染＋SVG合成层CSS | 50 | 14 | 0 |
| 异步渲染，主页连续拖动 | 50 | 0 | 0 |
| 异步渲染，人物图连续拖动 | 50 | 0 | 0 |
| 异步渲染，16次系统平移手势 | 50 | 0 | 0 |
| 最终无诊断版本，深色下16次系统平移手势 | 50 | 0 | 0 |

增加SVG合成层的方案效果更差，未进入正式资源。异步渲染四组共200张样本没有捕获空白或黑框。

## 3. 采用方案

`NativeGraph`由`SYNC_RENDER`切换为`ASYNC_RENDER`，保留`onInactive()`/`onActive()`可见性管理。普通返回不整页刷新；加载失败、渲染器退出与主题切换使用各自恢复路径。主页与人物图共用组件，因此两处一并生效。

该修改不改变布局算法、筛选、关系强度或缩放。诊断通道和临时调试代码不保留在正式产品中。

## 4. 返回路径与结论

另外检查5次后台返回、3次详情返回和1次放大后返回，9次未捕获黑框；隔离力导布局自然运动后，返回前后节点及缩放变换保持。

证据支持该方案改善既定模拟器场景，不能据此认定所有过渡帧、所有机型或更大图谱均无闪烁。尚无固定帧率、耗时或内存基线。后续视觉回归应同时检查生命周期恢复与持续运动，避免重新加入普通返回时的整页刷新。
