# 全面手测前排查与原版对照

日期：2026-10-22。范围：原版已实现功能，旧数据不迁移，原版工程只读。按用户要求，本轮不启动模拟器、不安装或执行设备测试。下列“已修改”以代码及本地验证为边界，不等于新版界面已经验收。

## 对照发现与处理

| 项目 | 原版依据 | 本轮处理 |
|---|---|---|

| 表单内分类管理 | chip-selector.tsx、relation-picker-sheet.tsx：创建／改名／删除分类 | 人物编辑新增“管理关系类型”；事件编辑新增分支／情绪管理入口，返回保留草稿；删除分类后移除草稿中的失效选项 |
| 未设置分支 | event-form-screen.tsx / use-event-form.ts | 补充“未设置”操作，一键清空分支 |

| 编辑后的卡片内容 | 原版通过查询失效重新取数 | 人物详情中的事件行更新 key；同时覆盖改参与者姓名、分类名后的卡片文字刷新 |

| 事件预设颜色 | config/event-presets.ts | 恢复原版六个预设色，保留用户已有自定义颜色与事件存色 |

## 数据与文件问题

- 头像保存前校验其存在、未删除且为图片；替换头像后，仅将已无任何人物／事件引用的旧头像标记为可清理。不会因为换头像删除仍被其他记录使用的图片。
- 备份恢复在同一事务内拒绝悬空／非图片头像引用；失败保留恢复前数据库。原 schema 没有头像外键，因此仅检查数据库外键不足以发现此问题。
- 备份导出打开目标失败时仍关闭源文件。清理资源逐项执行，避免某个关闭失败跳过后面的附件清理。
- 备份恢复已经提交后，归档关闭失败只记录清理日志，不再向界面返回“恢复失败”；事务失败时保留主要错误并继续清理本次复制文件。
- 录音准备失败、停止失败、空录音及页面释放时清理无用捕获文件；正常停止后保留文件供导入，导入完成再移除捕获文件。
- 等待麦克风初始化期间，如果应用已退后台或页面被释放，完成初始化后立即释放录音资源，不进入正常录音状态；录音中禁用图片／音频选择和分类跳转，避免可点击却静默无反馈。
- 人物表单保存期间统一禁用编辑操作，避免提交快照后又修改屏幕表单。

## 仍存在的适配差异与待验收项

- 分类管理位置、人物详情页代替原弹层、资料菜单代替径向菜单，布局／动画与原版有差异；常用功能已有入口。
- ArkWeb 复用原 D3，并非纯 ArkUI 绘图；真实设备的节点点击、拖动、主题切换及 50／200／500 节点性能仍需确认。
- 2026-10-25 AI 专项已增加到 13 个只读工具，补齐多轮、引用、本机聊天保存及常见表格／链接展示；服务设置已改为 URL／API Key／模型弹窗，通过 OpenAI 兼容接口直连。详见 ai-assistant-design.md。仍需用户所选真实提供方／模型验收兼容性、检索规划与关系分析质量，完整嵌套 Markdown 不承诺与 RN 逐项一致。
- 实际照片／录音导入播放、权限拒绝与系统中断、媒体备份完整往返仍需手测。
- 上轮“备份导出取消后未观察到提示”仍未确认。主机已验证取消返回和清理逻辑，但不能证明设备按钮／系统选择器的时序；不将它标成已修复或已复现缺陷。
- 旧版备份兼容、登录／会员／绑定／云同步／通知投递／自动更新仍按已确认范围排除；正式签名与商店发布单列。

## 建议手测顺序

只用明显标记的测试记录验证删除；备份恢复会替换本机数据，先保留一份当前备份，再在可丢弃的测试环境做恢复验收。

1. **人物与关系**：新建测试人物 A／B，选择 B 后改关系类型和强度，保存、重开；滑条数值随动，目标不变。多行关系删第一行后，剩余行仍对应正确人物。
2. **隐藏历史**：A 与 B 已有关系后隐藏 B，编辑 A 的名称及原关系强度仍可保存，B 不重新出现在人物列表。
3. **事件表单**：填写标题、文字、日期、地点，选择多名参与者、多个分支和情绪；进入管理页新增／改名／删除测试分类，再返回，草稿保持，删除的选择不会残留导致保存失败。“未设置”清空分支。
4. **保存与重开**：保存事件，编辑修改，再返回人物详情和事件列表，卡片显示新内容；强制停止后重开仍正确。
5. **筛选与搜索**：事件列表同时选两个分支，任意命中即可显示；再次点击可取消。搜索到详情再返回，搜索词保留；首页全局搜索不会被列表筛选漏掉记录。
6. **两类图谱**：人物图谱分别切换关系／分支筛选。生活分支图含“我”、相关分支及事件；不含“我”的测试事件仍在总列表，但不出现在个人生活分支图；未分类事件有连接，多分支事件不重复。
7. **附件与取消**：导入照片，设封面、移除、打开大图、保存重开；取消未保存表单后，再查看原已保存事件，其附件不应被误删。图片／音频选择器取消后页面可继续操作。
8. **录音**：拒绝权限有提示；正常录制、停止、播放和拖动进度；录音时切后台，返回后状态一致；等待权限／启动期间退出后不应继续录音。
9. **资料与外观**：称呼、简介、生日及清除生日；更换头像后旧事件中的图片仍可见。切换四主题及明暗模式，播放器、图谱控件可读，重开设置保持。
10. **备份**：空间统计可见；分别取消导出／选择文件并记录反馈。导出后恢复到测试环境，核对数量、关系、封面、音频与资料；损坏 ZIP 恢复失败应保留原数据。
11. **删除**：对测试事件取消／确认删除；测试人物分别验证保留历史与彻底删除，共同参与的事件保留，只由被删人物参与的事件按说明移除。
12. **AI 与流畅度**：配置实际服务，核对统计／人物／日期／情绪查询；查询中返回不应出现迟到回复。最后检查长文字、键盘、大字体、深色、大图谱和前后台切换。
