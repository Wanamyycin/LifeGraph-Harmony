# 桌面关系微图（2×2 紧凑版）

基于 `49a974c` 的现有应用新增普通 ArkTS 动态服务卡片，当前仅提供 2×2 紧凑版，占 4 个桌面格位。最初 4×4 原型已替换。不把应用内 Web/D3 页面嵌入桌面；卡片用原生 Canvas 和小球组件。

## 使用

1. 在 DevEco 打开当前 `LifeGraph-HW` 项目，签名后运行。
2. 应用右上角个人入口 → 我的 → 桌面关系卡片，选择最多 6 位人物，保存。
3. 桌面长按应用图标 → 服务卡片 → 关系微图 → 添加到桌面。卡片也有设置入口。
4. 点击人物小球直接进入人物详情，在应用里查看共同经历；右上角“⋯”和中心“我”进入卡片设置。
5. 点击“+ 记一件事”打开原事件编辑器。

所有实例共用一份人物/隐私设置。人物按照选择顺序占用固定位置；删除某人后其余节点不重新洗牌。只显示实际存在的关系连线，粗细来自手动填写的关系强度，不根据事件数量推断强弱。

## 隐私与数据

- 默认以序号隐藏姓名；可改为名字首字或记录中的称呼的前两个字。完整称呼和共同经历在应用里查看。
- 紧凑版不显示事件标题、摘要和共同记录数，仍显示图谱结构。设置页不再提供无效的事件标题开关。
- 共同事件必须同时包含“我”和该人物的参与者 ID，正文提及或他人独有事件不计入。
- 只向桌面提供六位人物的最小展示数据；不提供事件正文、地点、头像、照片、录音、API Key 或 AI 对话。
- 展示缓存和卡片设置存于应用私有 Preferences，独立于业务数据库，不进入应用现有 ZIP 备份。卸载后需要重新选择人物；恢复其他备份后，失效的 ID 不显示，需重新配置。
- 记录刷新后更新本地展示缓存，再向系统列出的所有同名卡片推送，也配置了系统周期刷新。紧凑版移除了占空间的手动刷新入口。扩展只读缓存，不打开或迁移业务数据库。
- 单个卡片推送失败不会阻止其他实例更新，不会把数据库保存成功误报为保存失败。设置页会提示卡片刷新失败；桌面可能暂时保留旧内容，需重新打开应用或重新保存卡片设置。

## 启动与编辑保护

`EntryAbility` 接收冷启动/热启动 Want，初始化完成前保留一个待处理请求，消费后清除。只接受设置、人物详情、新建事件三个动作。

正在编辑人物、事件、个人资料、分类、外观、服务配置、卡片配置或录音时，卡片请求被提示并取消，不覆盖草稿。完成当前操作后需要重新点击桌面入口。

## 2×2 调整与主页黑框回测

原型的 4×4 过大，改为 2×2，将桌面格位由 16 个减至 4 个，去掉事件摘要区和外置人物长标签。小球内显示序号/简称，详情全部回到应用。此次模拟器更新移除了不再受支持的旧 4×4 实例，随后已添加新的 2×2 卡片；应用记录没有清空。

主页黑框实测中，Web 的 SVG/人物 DOM 仍存在，但画面不显示。仅将 Web 改成同层同步渲染不能完整解决：从桌面卡片进入人物详情再返回仍可复发。随后补充可见性恢复。最初在恢复时同时刷新 retained Web 页面，虽然消除了黑框，但会清空首帧并重启 D3，产生闪烁且重置视口；此做法已移除。

当前正常隐藏/显示仅调用 `onInactive()` / `onActive()`，数据确有变化才发送新的图谱内容。保持既有 DOM、节点布局和缩放；加载失败、渲染器退出、用户手动重载与主动切换主题仍使用原来的恢复/重新加载路径。

无重载版本已在同一模拟器回测个人页返回、桌面卡片进入人物详情后返回、普通后台切回。放大图谱后，4 个节点返回前后的坐标、文本边界尺寸完全一致，页面显示正常，没有再现黑框。静态截图与坐标比对不能量化所有过渡帧；真机视觉流畅度仍待验收。

当前版本模拟器检查：

- 2×2 卡片添加成功，卡片实际边长为 525 px（本模拟器分辨率 1280×2832），桌面其余区域可用。
- 小球点击直接进入正确人物详情；右上角设置、快捷记事入口通过。快捷记事空表单已返回，没有新增记录。
- 首页 → 人物页 → 首页，首页 → 个人页 → 首页，以及桌面 → 小卡片人物 → 返回首页，均回测显示正常。
- 放大/缩小、从测试人物小球中心拖动通过，关系连线仍随节点移动。
- 浅色下主页显示正常；已恢复原来的深色模式，最终桌面保留 2×2 卡片及隐藏姓名配置。
- 构建通过；卡片宿主检查增至 13 项（增加紧凑简称检查）。真机和长期运行稳定性仍待验收。

发现并修复两处 UI 问题：

1. `Line.startPoint/endPoint` 使用百分比坐标时，本模拟器未显示连线。改用 Canvas 根据实际宽高换算数值坐标后，实测连线可见。
2. 只有父容器响应点击时，名称文字区域未触发点选。为名称文字绑定点击事件后，实测文字和小球均可点选。

验收后恢复原来的深色模式，恢复隐藏姓名/事件标题；桌面保留 1 个可操作卡片，应用留下 1 位“卡片验收甲”和 3 条带“卡片验收”前缀的测试事件，方便人工复现。其中 2 条是共同事件，1 条仅含“我”。未清空用户数据。
