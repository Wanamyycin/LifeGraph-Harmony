## 本轮发现与修复

DeepSeek 当前模型默认启用思考模式，携带 tools 时后续请求要求回传 reasoning_content；通用适配没有保留该字段。依据 [DeepSeek 思考模式说明](https://api-docs.deepseek.com/guides/thinking_mode/)，只对官方 HTTPS API 主机附加 `thinking: { type: 'disabled' }`，不向其他兼容服务发送此扩展字段。这使当前只保存最终回答的流程可完成工具调用，并避免测试产生额外思考消耗。

新增回归先复现缺失参数，再修复通过；本地回归总数更新为 94，主程序构建通过，当前构建已安装。

## 验证边界

只发送一条简短真实问题，没有执行长篇分析；一条问题可能包含多个工具往返，不等于一次 HTTP 请求。当前没有收集提供方 token 用量及账单，不推断准确费用。当前业务库为空，尚未验收有记录时的语义召回、来源跳转、连续追问和关系解读质量；本轮也未进行设备重启、长会话、弱网及性能测试。进程重启证据不等于设备重启证据。
