# 离线边界与权限说明

版本：1.0.0　｜　代码基线：`0cba655`

## 1. 应用运行范围

当前正式入口提供本机记录、图谱、媒体、桌面卡片和备份，不提供登录、会员、应用自有云同步或AI助手。底栏第五项为“我的”，该页面没有助手入口。历史助手的数据结构及纯逻辑测试保留用于兼容，不代表存在可用的在线服务。

主模块清单未声明`ohos.permission.INTERNET`，原生网络客户端已移除。图谱从包内读取HTML、脚本和主题，D3不依赖CDN。ArkWeb设置总体网络拦截、关闭任意文件访问并禁止混合内容；本地内嵌缩略图使用data URI，保留图片加载能力。

离线指应用业务没有自建在线请求路径，不等于整个设备与系统断网。系统桌面、照片选择器、备份或换机服务的行为由系统配置和服务决定。

## 2. 声明权限

当前`entry`主模块仅声明`ohos.permission.MICROPHONE`，场景为`EntryAbility`使用期间。`module.json5`中的reason引用字符串资源，实际内容为：

> 用于录制生活事件的语音附件；仅在用户主动点击录音并授予麦克风权限后使用，录音保存在本机，拒绝授权不影响其他功能。

录音由用户操作触发，界面处理授权拒绝，并在退后台或会话结束时停止、释放资源。该实现没有后台持续录音功能。

图片、音频导入和ZIP导入导出使用系统选择器，通过用户选定文件的URI处理内容；未声明全库相册读取、广泛文件读取、通讯录、定位、相机或传感器权限。使用选择器不等于应用取得完整媒体库访问权。

## 3. 本机数据与导出

RDB保存人物、关系、事件和配置，附件保存在应用私有目录。RDB使用S1安全级别，不声称应用额外实现了数据库或ZIP密码加密。图片导入是将所选内容复制到应用目录，不是上传到应用服务器。

ZIP按表导出配置，可能包含旧版本留下的兼容数据；不能宣称所有历史配置均被自动过滤。用户主动导出的文件由用户保管，应用内删除不同时删除外部副本。系统备份扩展已配置，不应将“无应用自有云同步”写成“系统不会备份”。

## 4. 依赖与核对

原生功能使用HarmonyOS系统Kit，本地图谱包含D3.js 7.9.0。系统Kit与随包脚本是技术依赖，不能据此虚构第三方远程收集行为；上架披露应结合所提交版本、平台表单口径和实际依赖清单填写。

`test-offline-release.cjs`对权限、网络客户端、本地资源和应用身份作静态回归；2026-10-30该组4项通过。既有签名APP内嵌权限也核对为仅麦克风。静态检查不等于网络抓包或第三方安全认证，发布平台检测另见[上架与平台检测结果](../04-迭代与质量保障/上架与平台检测结果.md)。
