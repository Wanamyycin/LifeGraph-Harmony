# 使用手册

适用版本：Life Graph 1.0.0

## 1. 开始记录

Life Graph在本机保存人物、关系和生活事件，无需登录。底栏从左到右为图谱、记录、加号、人物、我的。加号用于直接记下一件事；个人称呼、外观和备份位于“我的”。

首次打开后已有“我”和常用分类。可先在“我的→个人资料”设置称呼、头像及个人见解，生日可留空。

## 2. 添加人物与关系

进入“人物”，新建人物，填写名称，按需添加描述和头像。关系编辑中选择另一位人物、关系类型和强度；可以添加多行，记录该人物与不同人的关系。关系目标不局限于“我”，但不能选择本人建立自关系。

强度为1—5的手动标记，用于表达自己的感受，并非系统分析结果。保存后可重新打开人物详情核对。允许不同人物使用同一名称，区分时应结合描述和头像。

“我的→关系类型”可管理类型；人物编辑页也提供管理入口。删除类型只移除相应关系分类，不会删除人物。

## 3. 记下一件事

点击底栏加号，填写标题和发生时间，选择至少一位参与者。默认包含“我”，也可以取消后记录其他人物的事情。正文、地点、生活分支和情绪均可选；地点为自行填写，不调用定位。

生活分支和情绪支持多选。“未设置”用于清空分支。已有分类不合适时可通过管理入口新增或调整。

图片通过系统选择器导入，可设为封面；音频可以导入，也可以点击录音。只有主动开始录音时才申请麦克风权限。拒绝授权后仍可记录文字、导入图片或已有音频。录音时先完成停止操作，再离开编辑流程；应用进入后台会停止录音。

附件导入应用后保存在本机。取消编辑不会保存本次事件；已被其他记录使用的媒体仍会保留。保存后从详情页检查时间、参与者和附件。

## 4. 查看图谱

首页默认显示“我”与直接关联人物的人际图，可按关系类型筛选。拖动圆点调整布局，拖动画布移动视图，使用右侧加减按钮缩放；点击节点进入相应内容。

左下角可切换生活图：中心为“我”，周围连接“我”参与的事件及其他参与者。分支用于筛选事件，不是独立节点。人物详情中的图谱则围绕选中人物展示关系和事件。

图谱只显示当前范围内的数据。没有与“我”直接建立关系的人物，不一定出现在首页人际图；这不代表其记录丢失。拖至绘制边界外的圆点会被裁剪，可反向移动画布或缩小查看。

## 5. 找回记录

“记录”按月分组，默认最近在上。可展开月份、切换排序，并组合关键词、人物和生活分支筛选。关键词匹配标题或正文，多选分支表示命中任一分支。

人物筛选显示“与某人”，范围是该人物参与的记录，也包括没有“我”参加的事件。人物详情的相关记录采用相同范围。找不到预期内容时先检查仍生效的人物、分支条件，再清除筛选。

首页搜索可同时查找人物名称、描述以及事件标题、正文，不继承记录列表的分支条件。

## 6. 删除和分类管理

删除人物前区分两种操作：

| 选项 | 效果 |
| --- | --- |
| 保留历史 | 从常规人物列表隐藏，历史参与记录保留 |
| 彻底删除 | 删除人物及关系和参与关联；仅由此人参与的事件也删除，多人事件保留 |

删除事件不会删除参与人物。删除分支或情绪标签会移除相关分类关联，事件仍保留。重要内容建议先导出备份；应用没有操作撤销或回收站入口。

## 7. 外观与桌面卡片

在“我的→外观与主题”选择森林、海洋、日落或极简，并设置跟随系统、浅色或深色。选择保存在本机。

桌面添加卡片的具体入口依系统桌面而定，选择Life Graph的“关系微图”。在“我的→桌面关系卡片”选择最多六位人物并保存；所有卡片使用同一套配置。默认以序号隐藏称呼，可改为首字或称呼短标签。

卡片人物入口打开详情，记录入口新建事件，中心或设置入口打开配置。正在编辑或录音时，跳转会延后。卡片不展示照片、音频和事件正文；仍可见关系结构，应按使用场合选择展示人物。若提示配置已保存但部分卡片刷新失败，可稍后重试，以应用内记录为准。

## 8. 备份与恢复

进入“我的→本地备份与恢复”：

1. 点击“导出备份”，在系统文件界面选择保存位置。备份包含人物、关系、事件、媒体及个人设置。
2. 妥善保管ZIP。文件没有应用内密码加密，不宜存放在公开共享位置。
3. 恢复时点击“选择备份并恢复”，选择本鸿蒙版导出的文件，核对预览数量。
4. 确认后，备份内容将替换当前记录，而非合并。恢复前先另行导出当前数据。

上限为清单16MB、单附件512MB，总体写入和解包按1GB检查。旧Android版的备份不属于支持格式。恢复业务数据后，桌面卡片可能需要重新选择人物。

删除应用内内容不会删除已经导出的ZIP或系统备份。系统备份和换机行为由系统设置管理，与应用自有云同步不同。遇到导入校验错误时不要反复覆盖，先保留原文件及当前数据。
