# Life Graph 鸿蒙版

Life Graph（生活脉络）以人物、关系和事件整理私人生活记录。鸿蒙版使用ArkTS、ArkUI、ArkData和原生媒体能力；图谱通过ArkWeb加载随包分发的D3/SVG。

- 应用包名：`com.njulifegraph.lifegraph`
- 版本：`1.0.0`
- 发布状态：已正式上架华为应用市场
- 文档与代码基线：`0cba655`（文档统一核对日期见总目录）
- [完整项目文档](docs/README.md)：需求、研究、规格、架构、迭代、质量与使用

## 功能

- 人物资料、头像、任意两人关系及手动强度；隐藏保留历史或彻底删除。
- 多参与者生活事件，包含时间、手填地点、分支、情绪、图片与音频。
- 首页人际/生活图、人物关系与事件图，支持筛选、拖动、缩放及详情跳转。
- 月度记录、折叠与排序、人物和分支组合筛选、关键词搜索。
- 个人资料、四套主题、跟随系统/浅色/深色，以及本地ZIP备份恢复。
- 2×2桌面关系微图：最多六位人物、默认隐藏称呼、人物和快速记录入口。

当前为本机应用，没有登录、会员、应用自有云同步或AI助手入口。行为与约束见[功能规格](docs/01-项目与需求/功能规格与验收.md)，操作路径见[使用手册](docs/05-部署与使用/使用手册.md)。

## 构建与运行

在DevEco Studio打开本目录，完成Sync，启动匹配SDK的模拟器或连接设备，运行`entry`。工程目标为HarmonyOS 26.0.0，兼容声明为6.1.0（API 23）。

```powershell
./scripts/build-local.ps1
./scripts/build-local.ps1 -Target ohosTest
./scripts/build-local.ps1 -BuildMode release -AppPack
```

脚本默认复用`F:/DevEco Studio`，可通过`-StudioHome`指定。签名使用有权限的本机配置，不随公开资料交付证书或口令。产物目录、安装和身份核对见[构建与部署](docs/05-部署与使用/构建与部署.md)。原生预览不用于验证持久化。
